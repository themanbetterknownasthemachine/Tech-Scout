# Tech Scout 2026

Dieser Skill unterstützt bei der systematischen Recherche nach Innovationen, Trends und Best Practices im Bereich Machine Learning, Data Science und Data Analysis.

## Scouting-Framework

### Relevanz-Matrix

Priorisiere Funde nach diesen Kriterien:

1. **Direkte Anwendbarkeit** - Für ML, Data Science, Data Analysis
2. **Technische Reife** - PoC-ready vs. Forschungsphase
3. **Impact/Aufwand-Verhältnis** - Business Value vs. Implementierungskosten

### Kategorien (Prioritätsreihenfolge)

| Kategorie | Fokusthemen |
|-----------|-------------|
| Operative Effizienz | Forecasting, Automatisierung, Prozessoptimierung |
| Data Engineering | Pipelines, Snowflake, Airflow, dbt, Data Vault |
| Business Intelligence | Power BI, Visualisierung, Self-Service Analytics |
| Emerging Tech | GenAI, LLMs, Computer Vision, Edge ML |

## PoC-Scorecard

Wenn ein Fund PoC-Potenzial hat, bewerte ihn systematisch mit dieser Scorecard (Skala 1–5):

```
### PoC-Bewertung: [Titel]

| Kriterium                  | Score (1–5) | Kommentar                       |
|----------------------------|:-----------:|---------------------------------|
| Daten verfügbar?           |             | Haben wir die nötigen Daten?    |
| Technische Machbarkeit     |             | Stack-Kompatibilität, Aufwand   |
| Business Value             |             | Konkreter Nutzen für Pistor     |
| Champion im Fachbereich    |             | Domänenexperte vorhanden?       |
| Time-to-PoC               |             | Aufwand bis erste Ergebnisse    |
| Open Source / Code ready   |             | Code verfügbar + nutzbar?       |

**Gesamt**: [Summe]/30
**Empfehlung**: Starten / Vertiefen / Parkieren / Verwerfen

**Nächste Schritte** (falls Starten/Vertiefen):
1. [Konkrete Aktion]
2. [Konkrete Aktion]
3. [Konkrete Aktion]
```

### Bewertungslogik

- **24–30**: Sofort starten — ideale Bedingungen
- **18–23**: Vertiefen — gezielte Abklärungen nötig
- **12–17**: Parkieren — Beobachten, bei Veränderung neu bewerten
- **< 12**: Verwerfen — zu weit weg von unserer Realität

### Scoring-Hilfe

| Score | Bedeutung                                          |
|:-----:|---------------------------------------------------|
| 5     | Ideal — keine Hürden, sofort umsetzbar            |
| 4     | Gut — kleine Anpassungen nötig                     |
| 3     | Mittel — machbar mit Aufwand                       |
| 2     | Schwierig — signifikante Hürden                    |
| 1     | Blockiert — grundlegende Voraussetzungen fehlen    |

## Qualitätskriterien

### Prüfpunkte

- ✓ Primärquelle bevorzugen (Original-Paper, offizielle Firmen-Ankündigungen)
- ✓ Aktualität prüfen (idealerweise < 4 Wochen)
- ✓ Hype vs. Substanz unterscheiden
- ✓ Reproduzierbare Ergebnisse und Code verfügbar?
- ✓ Peer-reviewed oder nur Preprint?
- ✓ Anzahl Zitierungen / GitHub Stars als Qualitätsindikator

### Red Flags

- ⚠ Reine Marketing-Ankündigungen ohne technische Details
- ⚠ Übertriebene Versprechungen ohne Benchmarks
- ⚠ Closed-Source ohne Evaluationsmöglichkeit
- ⚠ Kein reproduzierbarer Code bei Methoden-Claims

## Anwendungsfälle

Nutze diesen Skill für:

1. **Trend-Übersichten** – Wöchentliche/monatliche Zusammenfassungen
2. **PoC-Bewertung** – Technologien mit der PoC-Scorecard systematisch bewerten
3. **Paper-Reviews** – Neue arXiv-Paper einordnen und bewerten
4. **Konferenz-Empfehlungen** – Relevante Events finden
5. **Experten-Recherche** – Thought Leader und Spezialisten entdecken
6. **Frühindikatoren** – Emerging Trends frühzeitig erkennen
7. **Reporting** – Wöchentliche, monatliche oder Quartals-Reports für Team und ICT erstellen

## Workflow

1. Definiere Suchfokus (Kategorie, Zeitraum, Spezifität)
2. Starte mit HuggingFace Trending Papers + arXiv cs.CL/cs.LG für aktuelle Paper
3. Prüfe Firmen-Blogs der relevanten Labs (Anthropic, DeepMind, Meta AI etc.)
4. Ergänze mit Twitter/X für Breaking News und Community-Reaktionen
5. YouTube-Kanäle (Two Minute Papers, Yannic Kilcher) für Video-Zusammenfassungen
6. Filtere nach Qualitätskriterien
7. Formatiere Ergebnisse nach Output-Format
8. Priorisiere nach Relevanz-Matrix
9. Identifiziere PoC-Kandidaten mit verlinktem Code
10. Bewerte PoC-Kandidaten mit der PoC-Scorecard (Score ≥ 18 → vertiefen)
11. Erstelle Report im passenden Format (Weekly/Monthly/Quarterly) falls angefragt
